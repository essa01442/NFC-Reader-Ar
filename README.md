# مدير قارئ ACR122U NFC

تطبيق احترافي بواجهة رسومية لإدارة قارئ ACR122U والبطاقات الذكية على نظام Linux (ويدعم Windows مع إعدادات إضافية).
يدعم اللغتين العربية والإنجليزية، وتغيير اللغة يتم فورياً دون إعادة تشغيل.

## المتطلبات
- Python 3.10+
- `PyQt6`
- `pyscard`
- `pynput`
- `pytest` (للاختبارات)
- حزمة pcscd (على نظام Linux) أو خدمة Smart Card على Windows

## التثبيت على Linux
للتثبيت على نظام Linux، قم بتنفيذ الأوامر التالية للحصول على المكتبات المساعدة:
```bash
sudo apt-get update
sudo apt-get install pcscd libpcsclite-dev pcsc-tools
```

ثم قم بإنشاء بيئة افتراضية وتثبيت المتطلبات:
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## التثبيت على Windows
على نظام Windows، فإن مكتبة `pyscard` تعتمد على خدمة Smart Card (PC/SC) المدمجة بالنظام. كل ما تحتاجه هو:
1. تثبيت Python 3.10+ من موقع python.org
2. فتح موجه الأوامر وتثبيت المتطلبات:
```cmd
pip install -r requirements.txt
```

## التشغيل
بعد تثبيت المتطلبات المطلوبة وتوصيل القارئ بجهازك، نفذ الأمر التالي:
```bash
python acr122u_app/main.py
```

## استكشاف الأخطاء وإصلاحها
إذا لم يتم اكتشاف القارئ أو واجهتك مشاكل في الاتصال:
1. **القارئ غير مكتشف:** انقر على زر "إعادة الفحص / Rescan" من تبويب الإعدادات.
2. **على نظام Linux:** تأكد من أن خدمة البطاقات الذكية قيد التشغيل عبر تنفيذ الأمر: `sudo systemctl status pcscd`. إذا لم تكن تعمل، قم بتشغيلها بواسطة `sudo systemctl start pcscd`.
3. **على نظام Windows:** تأكد من أن خدمة "Smart Card" قيد التشغيل التلقائي من خلال مدير الخدمات (`services.msc`).
4. **القارئ معلّق:** قم بفصل كابل USB للقارئ وإعادة توصيله.
5. تحقق من "سجل العمليات" (Log) أسفل الشاشة، فهو يعرض رسائل الأخطاء والاستثناءات بالتفصيل.

## تشغيل الاختبارات
يحتوي المشروع على اختبارات وحدة مبنية باستخدام مكتبة `pytest`. لتشغيلها والتحقق من سلامة الأكواد:
```bash
cd acr122u_app
pytest tests/
```

## الميزات
- اكتشاف القارئ والبطاقة بشكل تلقائي
- قراءة البيانات (الـ UID ومحتوى الذاكرة) مع عرض رسائل حالة ملوّنة.
- الكتابة على البطاقة مع التحذيرات اللازمة والتحقق من الإدخال (Hex بأطوال 4 أو 16 بايت).
- محاكاة لوحة المفاتيح لإدخال بيانات البطاقة تلقائيا.
- تبديل فوري بين العربية والإنجليزية (واجهات RTL/LTR).
- سجل كامل للعمليات.
